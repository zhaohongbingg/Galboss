# 黑山羊仆从 v5 改版说明（对照 YSM 参考板优化）

> 2026-11-16。依据用户提供的三视图参考板（`GOAT SERVANT (YSM Reference)`）对既有黑山羊模型做的第二轮大改。
> 本文件是 `BLACK-GOAT-SERVANT.md`（v1/v2 契约）的**增补**：骨骼契约、动画契约、Java 契约继续有效，
> 只有 §3/§4 的「几何/贴图」窗口被 v5 上调，理由写在下面 §5。

## 1. 这次改了什么（一句话）

v1–v4 是「幻魔者长袍 + 山羊骷髅头」的低模；参考板是**黑西装燕尾管家**。v5 把外观按参考板整体重做：
窄长山羊头颅 + 大幅外张的后弯角 + 红瞳 + 黑西装（翻领/胸袋巾）+ 白衬衫 + 酒红领带 + 灰马甲（纽扣/怀表金链）
+ 白手套（分指）+ 燕尾外套（前开衩露黑裤）+ 皮鞋 + 尾巴。**骨骼名、层级、pivot、6 段动画全部不变**。

## 4. 贴图（v5：128 → 256）

| 项 | v4 | v5 |
|---|---|---|
| 尺寸 | 128×128 | **256×256**（v4 最后已用满 90% 面积，装不下翻领/马甲/链子） |
| 面请求 / 面积 | 220 面 / 14686 px | **389 面 / 38425 px（59%）** |
| 色板 | 深靛长袍 + 金瞳 | **黑西装 4 阶 / 骨 5 阶 / 角质 5 阶 / 白衬衫 3 阶 / 灰马甲 4 阶 / 酒红领带 4 阶 / 白手套 3 阶 / 金 3 阶 / 红瞳 3 阶** |
| 发光遮罩 | 眼 + 角根符文 61 px | **只留红瞳 176 px**（角根不再有金色符文，参考板是纯黑角） |

绘制原则（v5 定稿）：**平面靠几何 + 逐面明暗读形，贴图只做低幅度的呢料/骨纹**。
v5 中段试过满屏散点噪声，实机+离线渲染都会把体块读成"颗粒"，已回退成"竖向渐变 + 稀疏织纹 + 可选描边"。

## 5. 契约变更（v1 §3/§4 的窗口上调）

| 条款 | v1 | v5 | 理由 |
|---|---|---|---|
| 立方体数 | 35~70 | **100~200（实测 102）** | 翻领 12 / 马甲 5 / 领带 2 / 手套 12 / 燕尾 12 / 螺旋角 10 是参考板的最小表达 |
| 贴图 | 128×128 | **256×256** | 见 §4；128 下马甲只有 7×16 px，画不出纽扣+金链 |
| 模型总高 | 31~32 | **30.8~32.2（实测 31.8）** | 角尖略超 1.95 格碰撞箱 0.6 单位（视觉无害） |

**没有改的**：`identifier`、贴图文件名、动画文件名/动画名、27 个骨骼名与层级、pivot、claw_anchor 空骨骼约定、
判定高度（实体碰撞箱 0.62×1.95 不变）、正面朝 -Z、渲染器与 glowmask 机制。

## 7. 已知差距（诚实清单，未做/做不到）

1. **头的"圆润感"不足**：参考板头骨圆整、吻部是斜面过渡；v5 是方盒 + 3 段楔，45° 看仍是方块拼合。
2. **角的曲线仍偏"折线"**：5 段直段拼接，参考板是平滑 S 曲线（需 8~10 段或斜置薄板，成本高）。
3. **外套偏窄**：参考板外套是厚实体块（正面几乎填满躯干宽度），v5 为了露出手套把侧裙收窄了，正面比参考板瘦。
4. **没有发光线/灰尘粒子**：参考板只是造型参考，未做特效层。
5. **arm.json 未重做**：本工具链没有工程切换接口，手臂视图仍沿用模板（v1 契约同款限制）。
