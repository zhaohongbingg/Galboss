# 七大罪技能实测表（v1）

> 采集方式：`runServer` 实机战斗 60 秒，`[STAKE]` 埋点直接打印 `hurt / fx / cast / pillar hit`。
> 时间：2026-11-23 22:5x；环境：MC 1.20.1 / Forge 47.4.10；玩家单向挨打（抗性 III + 生命恢复 VIII + 伤害吸收 X），七位全程满血。
> 复现：把 `StakeDebug.ENABLED` 置 true（或加 JVM 参数 `-Dgalboss.stakeDebug=true`）后进入黄金乡打一轮。

## 三、炼狱之柱（玩家侧）

- 突刺命中 **291 次**，相邻命中 tick 差主要为 **4**（`[4,4,4,17,2,2,40,0,4,0]`，0/2 来自同一 tick 多目标、17/40 来自停手间隙）。
- 单体单次掉血 **9.52**（对 6 护甲的路西法；裸伤害 10）。
- **结论**：右键"每目标每 4 tick 结算 10 点"成立，多目标各自独立计时。
